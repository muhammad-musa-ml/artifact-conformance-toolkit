CHECK-01 -- THE RED TRANSCRIPT
===========================================

What this file is, and what would make it worthless.

a design rule requires a committed RED transcript per checker, captured BEFORE the
implementation commit, with commit order as the evidence. The trap in that
requirement -- the research note names it as Pitfall 2 -- is that "before the
implementation" reads as "before any code exists", and a transcript captured
then records a missing module or an absent input. Each of those exits non-zero,
each satisfies a naive "non-zero exit" acceptance test, and none of them says
anything about whether the check DISCRIMINATES.

So tools/checks/check_01.py was REGISTERED AND RUNNABLE when this was captured,
with its detection logic stubbed to return a passing verdict over whatever it
read. Every failure line below is therefore an assertion about the VERDICT --
`assert 0 != 0`, `assert 0 == 1` -- produced by a check that really ran, over
inputs that really exist. The stub's own population line is quoted inside each
assertion message, so a reader can see what the check concluded and what the
test expected, side by side.

The two committed one-known-bad fixtures it ran against:

  fixtures/broken-artifacts/broken-figure-without-population/
      a figures.json entry carrying a population_label and no population
  fixtures/broken-artifacts/broken-figure-in-prose/
      a figure VALUE typed into un-rendered prose, in a shape the allow-list
      PERMITS -- the shape rule classifies it as a port and says nothing, so
      only the value check can catch it

The zero-input fixture is built in tmp_path by conftest.tmp_artifact with its
figures block empty: a check over zero figures must report DID-NOT-RUN, never
PASS.

REVIEW CRITERION FOR THIS FILE, stated so it can be checked rather than assumed:
the failure lines below must name ASSERTIONS ON THE VERDICT. A transcript whose
failure line instead names a failed module load, a collection failure, an absent
input, or an argument parser rejecting a flag is a FALSE RED and must be
rejected and recaptured. That is mechanically checkable with a case-insensitive
grep for those five shapes, and the plan states the pattern.

THE PATTERN IS DELIBERATELY NOT PASTED HERE. A transcript that quoted its own
needle set would match that grep against its own prose and fail the gate it
exists to satisfy -- and the natural repair for that, excluding this file from
the sweep, would put a hole exactly where the guard is supposed to be. Plan
an earlier plan measured what the same mistake costs: a text predicate that matched the
FILENAME it was written to protect produced 26 confident false findings. The
pattern lives in the plan's acceptance criteria and in the research note's Pitfall 2
warning-sign list. It returned 0 against this file when this was captured, and
against the raw pytest output before it was framed.
